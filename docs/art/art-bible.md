## 기계 (MachineKit 문법)
- 투입부(재료가 보이는 호퍼·탱크) → 가공부(일할 때만 움직임: 코일 발광·거품·회전·벨트) → 산출 받침대(앞쪽, 금색 테두리).
- 범용 상자 모델 금지. 무엇이 들어가 무엇이 나오는지가 모양으로 읽혀야 한다.
- 구역을 채울 만큼 크게(북쪽 시설은 키 1.25배, 온실 1.2배). 충돌 발자국은 WorldMap.STN과 맞춘다.
- 외곽선은 캐릭터·물건·기계에만(PostFX 마스크). 배경·바닥·연석·소품엔 없다.
- 받침·쟁반은 둥근 모서리(`MachineKit.RoundSlab`: 십자 상자 둘 + 모서리 원기둥 넷). 직각 판·어두운 쟁반은 네모 블록으로 읽힌다. 입력 쟁반은 옅은 회색 c4bcb0.
- 토양 정화기: 둥근 깔때기 호퍼 → 둥근 몸통 위 남북 축 드럼(동그란 앞면 창 안에서 흙덩이가 구른다) + 물 관 아치 하나.
- 해빙기와 병입기는 실루엣·강조색을 다르게(fb2, jake "제빙기 해빙기는 결국 유사한 디자인인 거니?"). 해빙기 = 열·녹임: 낮고 넓은 숯빛 화로(앞면 주황 불꽃 창 + 굵은 창살) 위 넓은 호퍼(주황·빨강 테)에 얼음이 4×3으로 펼쳐지고, 일하면 반투명 김이 피어오르고 동쪽 주둥이 물줄기가 둥근 수조에 고인다(굴뚝 하나, 강조 주황·빨강). 병입기 = 물·포장: 키 큰 유리 물탱크(뚜껑 없는 관, 바닥 30%는 늘 물) → 파란 관 아치 → 흰 제어함(파란 화면) → 컨베이어 위 충전 헤드의 파란 노즐 → 동쪽 파란 병 상자(금색 윗테)에 물병이 3×4로 선다(강조 파랑).
- 유리 탱크·관은 닫힌 원기둥 대신 열린 관(`MachineKit.Tube`)으로: 닫힌 윗면은 회색 원판으로 읽힌다.

## 유리·얼음
- 유리는 `Mats.Glass`(Shaders/MarsGlass): 가운데는 거의 비치고 가장자리만 옅은 하늘빛 테 + 해 쪽 반짝임 하나. 위에서 내려다보면(고도 55°) 프레넬 테가 거의 안 생기므로, 시설 유리(해빙기 고급 유리 돔·카운터 고급 진열장)는 `_VHi`=1 재질 + 메시 정점 알파에 하이라이트를 굽는다: 돔은 바닥 흰 테·북서쪽 굽은 반사 줄·반짝 점·남동쪽 옅은 반사, 진열장은 윗면 흰 테·옆면 위로 번지는 빛·뒤 벽 사선 반사 줄 쌍. 크림 바닥·밝은 호퍼 위에서 흰 유리가 묻혀 몸통은 옅은 하늘빛(돔 알파 0.26·진열장 0.42). 같은 메시 안이라 정렬이 고정돼 깜빡이지 않고 밝기 1 남짓(블룸 문턱 2.4 아래). 조명은 밝기만 따르고 색조는 무시(낮 분홍·밤 파랑 방지). 깊이를 안 써서 외곽선이 안 생긴다.
- 휴게 돔: 맑은 유리 + 안은 크림 원판 바닥(살구색 발판 모델은 숨김). 유리 너머 벤치·화단이 또렷해야 한다.
- 얼음 비침(r6, `Shaders/MarsIce`): 얼음은 모든 불투명 물체 뒤(AlphaTest+20)에 그리고, 그 직전 화면을 이름 붙인 GrabPass로 프레임당 한 번 떠서 면 법선만큼 살짝 밀어(가짜 굴절) 얼음빛(80cdff 쪽)을 곱해 섞는다(비침 양 0.55 × 정면일수록 많이). 정면 면은 색을 진하게(속 깊이), 비스듬한 면엔 흰 하늘빛 가장자리 밝힘(프레넬, 밤엔 35%로). 깊이를 쓰는 불투명이라 정렬 깜빡임이 없고 외곽선은 바깥 둘레만. 정점 색 알파 = 비침 양: 깎은 위 모서리 0.3·반사 줄 0으로 흰빛이 남는다. 뒤 화면에 1 아래 색을 곱하므로 뒤보다 밝아지지 않고 테는 0.35 남짓(블룸 문턱 아래). 그림자 위 얼음은 반쯤 어둡게 비쳐 뒤가 보이는 느낌이 난다.
- 유리 가장자리 밝힘(r6, MarsGlass `_RimAdd`·`_RimPow`): 해빙기 유리 돔 0.75·지수 1, 카운터 진열장 0.7·지수 1. 돔 둘레가 흰 하늘빛 타원 테로 읽힌다. 밤엔 35%로.
- 얼음(더미·등짐·호퍼·물건 모두 같은 언어, `Items.ICE_*`): 모서리를 깎은 하늘색 덩어리(`ToyMesh.Bevel`) — 큰 면은 가운데가 진한 파랑(코어)에서 둘레로 옅어지고, 깎은 위 모서리는 흰빛, 윗면은 한 톤 밝게. 불투명 정점 색이라 투명 정렬 깜빡임이 없고 외곽선이 바깥 둘레에만 생긴다. 따뜻한 햇빛에 회백색으로 바래지 않게 제 색 발광 0.16(`_Self`, 밤엔 꺼짐). 더미는 큰 덩어리 + 앞 오른쪽에 기댄 덩어리 + 위 조각으로 한쪽에 쏠리게(양옆 대칭이면 소파처럼 보였다). 예전 유리 껍질은 뺐다. 투명감은 윗면 사선 흰 반사 줄 둘(`ToyMesh.Glint`, f2fbff, 0.15 띄운 얇은 판: 불투명이라 깜빡임·안쪽 외곽선 없음)로만 보탠다(더미·물건 얼음).

## 모형 만들기(fb2)
- 얇은 판(두께 2~3 이하 상자·납작 원기둥)을 붙여 모양을 내지 않는다(jake "판떼기만 붙여 둔 것 같다"). 두툼하고 둥근 덩어리: 깎은 상자·원뿔대·울퉁불퉁 덩어리를 `ToyMesh`로 한 메시에 합치고 정점 색으로 칠한다(`Shaders/MarsVColor`, 드로우콜 1·같은 모형 인스턴싱). 테·띠도 두께 있는 고리(`ToyMesh.Ring`·`Band`).
- 물건(`Items.Slab`): 물병 = 진한 아랫몸·크림 라벨·밝은 윗몸·어깨·남색 뚜껑, 산소통 = 흰 실린더·파란 띠·밸브, 식량 = 노란 감자 상자, 흙·비료 = 둥근 자루(갈색·초록), 레골리스 = 붉은 저폴리 돌, 얼음 = 깎은 얼음 덩어리, 지폐·동전은 예전 판. 병입기 상자·카운터 칸·정착민 손(2열)·날아가는 물건이 모두 같은 모형. 더미 간격은 `Items.Gap`.
- 나무(테라포밍): 통통한 저폴리 나무(둥근 수관 1~2덩어리 + 짧은 줄기, 초록 2톤) + 둥근 이끼 방석(두 단 원판, 테두리 깔끔한 원). Kenney 자연 팩 나무는 육각 기둥형이라 쓰지 않았다.
- 돌: 포인트 바위·레골리스 더미는 둥글고 덩어리감 있는 저폴리 돌무더기(큰 돌 + 작은 돌, 붉은 갈색 3톤: 윗면 c45f3a·옆 9c3f26/86351f·아래 5a2216). Kenney 바위는 납작한 판형이라 쓰지 않았다.
- 정점 색 모형은 밤에 `_MarsNight`(DayNight 전역 값)만큼 채도를 덜어 하늘색이 진한 파랑으로 튀지 않는다.

## KayKit(10/26 한 장면 시범, kk-slice)
jake "판떼기 붙인 것 같다", "엉성하다"가 반복돼, 코드로 상자·원기둥을 조합하던 기계를 프로 아티스트 한 스타일 키트(KayKit Space Base Bits·Restaurant Bits, Kay Lousberg, CC0)로 바꾸는 시범. 기지 중심(해빙기·병입기·카운터·계산대·드릴) + 착륙선 + 소품 넷만 바꿨고 나머지 맵은 예전 모형. 비교 [compare_kaykit_v1.png](compare_kaykit_v1.png)(윗줄 기지 중심 전·후·목표·밤 전·후, 아랫줄 기계 확대 전·후 낮·밤·착륙선 전·후). 검증 인자 `-kk 0`이면 예전 모형.
- 파이프라인: 아틀라스 텍스처를 쓰지 않는다. `tools/kaykit_bake.py`가 정점마다 UV 자리 아틀라스 색을 정점 색으로 구워(세로 그라데이션은 정점 보간으로 남음) `kk_<이름>.bytes`로, 게임은 `ToyMesh.Kk`로 우리 부품과 한 메시에 합친다. 외곽선·그림자·인스턴싱·레벨 솟아오름(TierLook)은 예전 그대로.
- 키트 부품이 주인공, 우리 부품은 최소한: 기지 모듈·지붕판·착륙선·카운터·상자는 KayKit, 게임 고유 부품(얼음 호퍼·유리 물탱크·수조·컨베이어·충전 헤드·불꽃 창)만 남기고 KayKit 톤으로 칠한다: 밝은 회색 외피 `e9e8e1`·`c9ccc7`, 짙은 회색 틀 `545b5f`·`3f4549`, 중간 회색 `8e9597`, 주황 띠 `f07b36`. 산출 받침대 금색 윗테·물 파랑은 그대로.
- 색: KayKit 흰·회색은 푸른 기가 있어 무채색만 살짝 데운다(`KK.Warm`). 부위 색을 바꿀 땐 색상 범위로 바꾼다(`KK.Hue`): 카운터 주황 나무 상판 → 기본 밝은 나무 `dcb88c`·개량부터 하얀 상판, 계산대 상판 → 남색 `5b6b8c`, 돌 주황 → 붉은 갈색 `9a4529`.
- 스케일: KayKit 1단위 = 논리 15~40. 비균등 스케일은 1.6배 안쪽(카운터는 220×36 띠에 맞추려 칸 6개를 이어 키 32로). 납작한 판(roofmodule_base)은 시설 받침으로 눌러 편다. 모델 앞면(문·서랍)은 남쪽(카메라 쪽)을 보고, 해빙기 모듈만 문이 얼음밭 쪽(서)을 보게 돌린다.
- 기계 문법은 그대로: 해빙기 = 모듈 지붕 위 호퍼에 얼음(투입) → 남쪽 벽 불꽃 창·김(가공) → 동쪽 수조 물(산출). 병입기 = 유리 탱크 → 관 아치 → 모듈(문 앞 컨베이어) → 나무 상자(금색 윗테). 앵커는 높이만 새 모형에 맞춤(호퍼 바닥 31.5, 상자 바닥 14.5, 카운터 상판 32).
- 레벨 3단계는 키트 부품을 더하는 방식: 해빙기 개량 = 금속 테·굴뚝 둘·파란 물통 묶음(containers_C), 고급 = 금 테·유리 돔·물통 위 태양판. 병입기 개량 = 지붕 위 물통 묶음, 고급 = 금 테·긴 컨베이어·상자 둘·로봇 팔. 카운터·계산대는 상판 색·테·유리 진열 벽(예전 부품, 높이만).
- 착륙선은 기계처럼 외곽선을 받게 배경 루트 밖(`KKLander`). 소품(화물 더미·돌)은 배경(외곽선 없음), 과하지 않게 넷.
- 남은 것: 카운터는 늘 있는 차양에 가려 기본 줌에선 윗면만 보인다. 밤(-clock 200)은 낮과 차이가 작다. 나머지 맵은 아래 r7 에서 옮겼다.

## KayKit 통일(10/26 r7, r7-kkall)
시범 계획대로 나머지 맵 시설·소품의 외형을 같은 `ToyMesh.Kk` 조합으로 옮겼다. 충돌·반경·좌표·앵커 수평 위치·애니메이션은 그대로이고 높이만 맞췄다. 비교 [compare_kaykit_v2.png](compare_kaykit_v2.png)(윗줄 낮·가운데 줄 밤: 기지·북쪽·개척지 쪽·맨 아래를 장소마다 전·후, 아랫줄 확대 전·후: 북쪽 시설·개척지·휴게 돔·본부와 우리). `-kk 0` 이면 예전 코드 모형(Kenney GLB 를 쓰던 자리는 빈 자리).
- 북쪽 4시설(`SettleStationsKK.cs`): 전기분해기 = basemodule_A + 지붕 위 전해조(물·전극·거품) + 양옆 기체 탱크(산소 파랑·수소 주황 띠), 토양 정화기 = basemodule_D + 서쪽 깔때기 호퍼(붉은 레골리스) + 지붕 위 남북 축 세척 드럼(앞면 창 안 흙덩이), 비료 배합기 = basemodule_A + 지붕 위 깔때기 흙 더미 위로 도는 배합 날개 + 서쪽 초록 비료 통(containers_A 두 단), 온실 = 남북 유리 터널(KayKit 톤 둥근 아치 살·짙은 문턱) + 동쪽 KayKit 통로(tunnel_straight_A) → 물탱크, 작물은 KayKit 상추. 키 1.25배(Grow)는 모듈 비율이 늘어나 쓰지 않고 모형을 키웠다. 받침판·쟁반은 예전 그대로. 앞 아치에 주황 띠를 겹쳤더니 큰 주황 호로 튀어 뺐다.
- 레벨 3단계(북쪽): 본체는 테 색만(주황 → 금속 → 샴페인 금), 단계 부품은 KayKit 부품이 솟는다: 전기분해기 개량 = 탱크 잇는 관 아치·화물 상자(cargo_B), 고급 = 전해조 유리 덮개·태양판 / 정화기 개량 = 작은 물탱크, 고급 = 지붕 태양판 / 배합기 개량 = 모터 상자(cargo_B)·깔때기 띠, 고급 = 모터 위 태양판 / 온실 개량 = 둘째 탱크·살수관, 고급 = 금 살·조명 띠·태양판.
- 본부(`HQSystemKK.cs`): Lv1 basemodule_C → Lv2 structure_tall 철골 위 레이돔 + 모듈 지붕에 roofmodule_cargo_A(쌓아 올림) → Lv3 basemodule_E(KayKit 금빛 돔은 금색 규칙과 섞여 옅은 하늘빛 유리색으로, 창 불빛) → Lv4 roofmodule_solarpanels + 깃발 → Lv5 키 큰 structure_tall 위 유리 관제실. 솟아오름·발자국 그대로.
- 개척지(`FrontierKK.cs`): 거주 돔 = basemodule_E(돔은 흰 외피, 아래 띠만 집 강조색), 남동쪽 둥근 창 하나. 태양광 = KayKit solarpanel 의 파란 판만 떼어 눕혀(짙은 회색 테 위) 예전처럼 해 쪽으로 기운다. 배터리 = structure_low 받침 위 흰 원통 + 초록 막대, 변환기 = cargo_B + 환풍기.
- 휴게 돔(`DomeSystemKK.cs`): 좌석 = Restaurant 의자(서쪽 줄 청록·동쪽 산호) + 아래 두 줄 바깥쪽 작은 둥근 탁자(맨 위 줄은 유리 벽에 닿아 뺐다), 화단 = 나무 상자(crate) 화분 + 테라포밍 나무, 분수 = 그릇(bowl) 수반 둘 + 기둥(물줄기·물방울 높이 그대로), 에어록 = tunnel_straight_A 를 남북으로.
- 토끼 우리(`PenSystemKK.cs`): 건초 → 상추 상자, 당근 밭 → 당근 상자, 물그릇 → bowl, 토끼집 → 작은 basemodule_B(문등·표시등 그대로). 울타리는 ZoneManager 라 손대지 않았다.
- 가장자리(`WorldDressKK.cs`): 포인트 바위 = rocks_B + rock_A(붉은 갈색), 앞(남) 낮은 메사 둘 = terrain_tall_curved 다섯 덩이(지층 색), 로버 = spacetruck, 북쪽 배관 끝 탱크 = KayKit 톤 탱크.
- 물건: 식량(감자 상자)만 Restaurant crate_potatoes 로(진열·등짐 크기·간격 그대로). 물병·산소통·흙/비료 자루는 Restaurant Bits 에 맞는 게 없어(병은 소스 통, 자루 없음) 우리 모형 그대로.
- 캐릭터(정착민·플레이어·토끼)는 그대로: 둥근 프리미티브 몸 + 외곽선이라 KayKit 기계(각진 저폴리·정점 색 그라데이션) 옆에서 더 매끈하고 장난감 같다. 색은 같은 파스텔 계열이라 크게 튀진 않는다. → 아래 "캐릭터(10/26 r7-chars)"에서 같은 언어로 바꿨다.
- 빌드 정리: KayKit 모드에서 안 쓰는 Kenney GLB 22개 + colormap 텍스처를 Resources 에서 뺐다(로켓 4단은 이주 연출·`-kk 0` 착륙선이 써서 남김). resources.assets 3.92MB → 3.34MB.
- 남은 것: 앞 메사 지형 조각은 각진 덩어리라 매끈한 예전 메사 옆에서 조금 상자처럼 보인다. 개척지 거주 돔은 팔각 모듈이라 예전 이글루보다 통처럼 읽힌다. 기본 줌에서 정화기 드럼 앞면 창은 작게만 보인다.

## 동쪽 지역(3·4장, 10/26 이어지는 세계)
docs/chapter3-design.md. 기지와 같은 문법(크림 길·맨땅 바닥·메사 테두리·금색은 상호작용만) 위에 KayKit Space Base Bits 조합만 새로 얹는다(`RegionDress`).
- 길: 상점 북쪽 띠(y 392~440)를 그대로 동쪽으로 잇는 크림 타일. 기지 동쪽 메사 벽을 북·남으로 갈라 고개를 내고 그 안에 관문(둥근 회색 기둥 둘 + 주황 띠 + 빨간 등, 주황·흰 차단봉). 잠긴 길·지역은 측량 점선만, 지역 발판이 보이면 윤곽.
- 우주항: 맨땅 위 연회색 콘크리트 받침(착륙장·시설 터) + 광장 길에서 갈래 길. 착륙장 = landingpad_large, 화물선 = lander_B(금빛 돔) + 짐 상자, 연료 공장 = basemodule_D + 초록 탱크(roofmodule_cargo_A) + 지붕 호퍼(물통) + 동쪽 금테 받침대(연료통), 발사대 = landingpad_small + 발사탑(structure_tall) + 우리 로켓(흰 몸통·주황 띠·원뿔 코·핀 넷), 관제탑 = structure_tall + basemodule_E 돔(Lv2 탱크·레이더, Lv3 옆 모듈·금 테).
- 화물선 역추진 불꽃: 몸통이 넓어 고도 55° 카메라에선 가운데 불꽃이 가려지므로 다리 끝 작은 불꽃 넷을 같이(제 색 발광, 화면 번쩍임 없음). 착지 땐 먼지 고리 + 흰 링 하나.
- 연료통(새 자원): 초록 34b37e 통 + 흰 띠 + 짙은 뚜껑(KayKit 초록 탱크와 같은 계열, 비료 올리브 8fae4a와 구별).
- 얼음 협곡: 바닥은 조금 차가운 맨땅 cc9478 + 광맥 쪽 옅은 서리 얼룩 둘. 광맥 = 물건 얼음과 같은 MarsIce 덩어리 더미(잠긴 동안에도 보여 다음 지역 실루엣 역할), 정제소 = basemodule_garage + 노란 탱크 + 지붕 호퍼(얼음), 채굴 로버 = spacetruck_large + 트레일러(실은 얼음이 보임). 벽은 메사 복제 + 메사 돌 색 KayKit 바위. KayKit 지형 블록(terrain_tall·slope)은 시험해 보니 상자·판처럼 보여 쓰지 않았다.
- 동쪽 메사: 지역 띠(y 180~680)가 화면 높이보다 낮아 북·남 벽이 늘 보이므로 기지 메사보다 낮고 납작하게(북 0.6배, 남 0.3배 높이).
- 우주 연출: 궤도선 그림자(옅은 갈색, 가장자리 번짐), 밤 발사 불꽃(작은 불꽃 + 줄어드는 꼬리). 둘 다 글자·번쩍임 없음.

## 캐릭터(10/26 r7-chars)
KayKit 통일 뒤 둥근 프리미티브 캐릭터가 각진 기계 옆에서 "더 매끈한 장난감"처럼 따로 놀아, 플레이어·정착민·삐걱·뽀삐(+손수레)·먼지 토끼를 같은 언어로 다시 만들었다(`CharacterKitKK.cs`, 토끼는 `CharacterKit.BuildBunny`). 비교 [compare_chars_v1.png](compare_chars_v1.png)(윗줄 기지 기본 줌·줄과 삐걱 확대·밤 전·후, 아랫줄 걷기·토끼·뽀삐·VIP·휴게 돔 확대 전·후). 검증 인자 `-chars 0` 이면 예전 캐릭터.
- 조각은 셋만: 저폴리 공(`ToyMesh.Gem`, 둘레 8~16칸, 법선을 면 쪽으로 35%만 섞어 실루엣은 각지고 면은 살짝만 각짐: 완전 평면 셰이딩은 구겨진 종이·돌처럼 보였다), 모서리 깎은 상자(`ToyMesh.Chamfer`, 세로 그라데이션), 각진 원뿔대(`Cyl` smooth 끔). 매끈한 구·얇은 판·토러스 없음. 띠·목 링도 두께 있는 고리(`Ring`).
- 색은 KayKit 팔레트에 위가 밝고 아래가 어두운 그라데이션: 우주복 흰색 f6f3ec→d6d3ca, 주황 포인트 f07b36(벨트·장갑·목 링·산소통 마개), 짙은 회색 545b5f·3f4549(장화·바지·로봇 다리), 중간 회색 8e9597(배낭·로봇 팔), 바이저 남색 1f2b40→3a5680, 가슴 화면 파랑 3d8fd0. 정착민 옷 4색·VIP 금색은 그대로.
- 치비 비율 유지: 머리(헬멧)가 키의 절반 가까이. 플레이어 헬멧 반지름 15.6(꼭대기 63.5), 정착민 12.4(꼭대기 54). 피벗(팔·다리·머리)·등짐 앵커(0,34,−25)·손 위 물건(56, VIP 66)·말풍선(머리 + 20, VIP + 26) 자리는 예전과 같아 애니메이션·말풍선·VIP 표시가 그대로 맞는다.
- 바이저: 헬멧과 같은 16×8 칸을 따라 정면 3줄(가운데 두 줄 5칸·아래 3칸)만 1.4~1.7 띄운 껍질(`ToyMesh.GemShell`, 가장자리는 벽으로 막음). 따로 만든 타원을 헬멧에 박으면 두 저폴리 면이 엇갈려 경계가 톱니로 보였다. 반짝임은 왼쪽 위 칸에 면을 보고 눕힌 작은 공 하나.
- 로봇(삐걱·뽀삐): KayKit 기계처럼 깎은 상자 몸 + 주황 띠 + 짙은 가슴 패널, 밝은 회색 머리 + 짙은 얼굴 화면 + 민트 눈 + 양옆 회색 볼트 + 금 비콘. 뽀삐 손수레는 나무 대신 밝은 회색 짐칸(윗면 중간 회색) + 주황 띠 + 짙은 받침 + 팔각 바퀴(KayKit spacetruck 톤).
- 토끼: 몸·머리·발·꼬리·귀·코 모두 저폴리 공, 황갈색 그라데이션(e9bd86→b0804e). 몸·코는 지름 1 메시라 숨쉬기·깡충 늘어남·코 씰룩 스케일 애니가 그대로.
- 드로우콜: 부위마다 한 메시(플레이어·정착민 20여 개 → 6개: 몸·머리·팔 둘·다리 둘, 로봇 10여 개 → 2~3개, 토끼 9개 → 5개), 같은 메시는 인스턴싱. 재질은 기계와 같은 MarsVColor 이되 밤 채도 덜기만 0.3 몫(`_NightSat`): 1이면 밤에 주황 포인트·옷색이 회색으로 바래 플레이어가 묻혔다.
- 외곽선은 예전처럼 포스트 외곽선(불투명 깊이), VIP 금 외곽선은 hull 이 새 메시에도 그대로 붙는다.

## 개척지(2장)
- 거주 구역: 낮고 넓은 흰 돔(이글루) + 아래 강조색 띠(파랑·산호·청록·보라 돌림) + 짧은 현관과 같은 색 문 + 동쪽 앞 둥근 창 하나(창 둘 + 문이면 얼굴처럼 보여 하나만). 입주하면 창에 불, 밤엔 환하게.
- 태양광 단지: 긴 줄 대신 네모난 패널 낱장(흰 테·파란 판·칸 줄)이 짧은 기둥 위에서 각자 해 쪽(남)으로 기운다. 배터리 탑은 흰 원통 + 초록 막대 5칸.

## 발판·상점
- 발판은 크림 원판 대신 옅은 금빛 바닥 + 늘 보이는 금색 고리. 살 수 있으면 고리가 밝아지고 바깥 고리가 숨 쉰다.
- 카운터는 밝은 나무 몸통 + 크림 상판, 칸 받침판은 옅은 톤(물 하늘·산소 흰빛·식량 밀색)으로 둘레에 상판이 테처럼 남게.
- 차양 기둥 끝은 금 구슬만. 기둥 위 깃대·깃발은 보라 깃발 장식을 샀을 때만, 기본 깃발은 서쪽 하나.
