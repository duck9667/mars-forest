## Overview
웹 앱(`app/index.html`)의 피자레디식 루프를 Unity 6(6000.0.85f1)로 옮긴 뒤, 화성 정착이라는 이야기를 입혀 초기화 없이 동쪽으로 계속 넓어지는 네 장짜리 게임으로 키웠다. 코드는 `unity/Assets/Scripts/`에 있고 씬 파일 없이 `Bootstrap`이 모든 시스템을 런타임에 조립한다. 2026-10-24 포팅(Phase 1~3)부터 10-26 밤샘 다듬기까지의 결과이며, 자동 플레이 봇 기준으로 1장은 약 24분, 2장은 약 45분, 3장은 약 36~42분, 4장은 약 33~36분이 걸린다(사람은 1.3~1.6배로 추정, 3·4장은 docs/pacing-report.md 2026-10-27 측정).

## What Is In The Game
1장 "생존"은 얼음을 캐서 해빙기로 물을 만들고, 병입기·전기분해기·토양 정화기·비료 배합기·온실로 물·산소·흙·비료·식량을 만들어 정착민에게 공급하는 다섯 단계다(물 확보 → 숨 쉴 공기 → 흙 살리기 → 첫 수확 → 생존 완료). 정착민은 물·산소·식량 중 하나를 요구하고 카운터는 종류별 3칸이다. 2장 "마을"은 북쪽 개척지의 태양광 단지(기계 속도 +20%)와 거주 구역(정착민 입주, 인구·세금), 착륙선이 관제탑까지 자라는 기지 본부 Lv0~5로 이어지는 다섯 단계다(전력 확보 → 첫 이웃 → 기지 정비 → 자급 마을 → 화성 마을 선포). 관제사 하나의 무전이 인트로·구역 해제·단계 달성·엔딩을 짧게 알려 주고, 화성 하루(300초)마다 하루 미션 3개가 나오며, 가끔 먼지 폭풍·보급선·얼음 운석 이벤트가 일어난다. 3장 "우주항"(화물선 주문·연료 공장·발사대·관제탑)과 4장 "얼음 협곡"(광맥·정제소·채굴 로버)은 기지 동쪽 길로 걸어가 이어 키우는 지역이고(docs/chapter3-design.md), 3장부터는 불시착 우주선 수리, 화물선이 떨구는 보급 캡슐, 밤하늘의 궤도 화물선·정거장이 글자 없이 연출된다. 그 밖에 뽀삐 운반 로봇, 얼음 드릴, 먼지 토끼 우리, 휴게 돔, 장식 6종, 부재 수익, 핀치 확대, 진동·소리 설정이 있다.

## Design
정답지는 제미나이 웹으로 게임 스크린샷을 다시 칠한 목표 그림(`docs/art/target_*_v1.png`)이고, 규칙은 `docs/art/art-bible.md`에 있다. 원칙은 덜어내기다: 배경·바닥·연석·소품엔 외곽선이 없고(외곽선 마스크 카메라), 균열·자갈·바퀴 자국 같은 바닥 잔무늬와 떠다니는 먼지, 화면 전체 번쩍임(이주·정착 완료 제외)을 없앴다. 기지 안 구역은 크림 타일, 개척지는 맨땅에 둥근 연석, 길은 크림 타일이다. 기계는 투입부 → 움직이는 가공부 → 산출 받침대 문법(`MachineKit`)으로 무엇이 들어가 무엇이 나오는지가 모양으로 보이게 만들었다. 전후 비교는 `docs/art/compare_v1~v3.png`.

## How To Build And Install
- 맥에서 바로 해 보기: `./tools/unity-qa.sh`로 맥 빌드를 만들고 `open -n unity/Builds/Mac/MarsBottle.app --args -save play`로 띄운다(마우스 드래그·WASD 이동, 휠 확대). `-save 이름`으로 저장을 나눌 수 있다.
- 아이폰 설치: 폰을 케이블로 연결하고 잠금을 푼 뒤 `./tools/ios-install.sh`. Unity iOS 빌드 → 서명 없이 xcodebuild → 받아 둔 개발 프로파일로 직접 서명 → `devicectl` 설치까지 한 번에 한다(약 10분). 프로파일(com.jakekwak.marsforest)은 2026-10-30에 만료되고, 만료 뒤나 다른 맥에서는 Xcode에 Apple ID로 로그인해 자동 서명 빌드를 한 번 해서 새 프로파일을 받아야 한다(무료).
- 자동 검증: `QA_ARGS="..." ./tools/unity-qa.sh`는 앱을 숨김·무음으로 띄워 자동 플레이 봇을 돌리고 스크린샷을 남긴다. 인자 목록은 `unity/README.md`.

## Known Gaps
- 길 폭이 목표 그림(약 60)보다 좁다(20). 구역 배치를 옮겨야 해서 보류.
- 4장 17단계(협곡 연료 200)와 3장 12단계 힌트는 고친 뒤 한 판만 쟀다. 3장 14→15단계와 4장 16단계는 발판 값을 모으느라 한 단계에 10~17분 걸려 실제 플레이를 보고 값을 낮출지 정한다.
- 불시착 우주선은 착륙장을 다 지은 뒤의 빈터 위치, 궤도 불빛 밝기를 실기기에서 보지 않았다.
- 실기기에서는 생존 기지 이전 빌드까지만 확인했다. 이후 변경은 맥 빌드 자동 검증만 거쳤다.
- `~/Documents` 아래 git 워크트리에서 Unity 빌드가 ILPP·bee 단계에 멈출 수 있다(메인 체크아웃은 정상). `DOTNET_USE_POLLING_FILE_WATCHER=1`로 일부 풀린다.
