## 초기화 없애기

이주(PrestigeManager)는 코드만 남기고 화면에 내보내지 않는다: 시트 맨 위 이주 카드, 지도·엔딩의 "새 정착지로"가 사라진다. 2장 엔딩 마지막 컷은 "동쪽 우주항이 기다려요!"이고, 지도 알약은 3장 0/5로 넘어간다. 이주 준비금(fund)은 시트에서 뺐고, 옛 저장에서 이미 낸 금액은 한 번 벨로 돌려준다(우주항 건설 기금, S.fundBack). 옛 저장의 prestige 값(병값 배율)은 그대로 두되 새 흐름의 조건으로 쓰지 않는다.

## 세계 확장

기지(x 0~400)는 그대로 두고 동쪽에 지역을 붙인다. 지역은 `Regions.ALL` 표 한 줄씩(이름·장·사각형·길·발판·바닥색)이라 다음 지역도 같은 방식으로 붙인다.

| 지역 | 논리 x | 논리 y | 들어가는 길 | 발판 |
|---|---|---|---|---|
| 기지 | 0~400 | −640~1040 | | |
| 우주항(3장) | 640~1080 | 200~660 | 1번 도로 x 386~640, y 396~436 | 1번 도로 `road1` → 우주항 `port` |
| 얼음 협곡(4장) | 1240~1680 | 180~680 | 2번 도로 x 1080~1240 | 2번 도로 `road2` → 협곡 `canyon` |

- 길은 상점 북쪽 띠(y 392~440)를 동쪽으로 잇는 크림 타일. 기지 동쪽 메사 벽을 둘로 갈라 길이 지나는 고개(관문)를 냈다. 관문엔 기둥 둘과 차단봉, 잠긴 동안 길·지역은 측량 점선만 보이고 발판을 사면 차단봉이 올라가며 길이 깔린다.
- 걸어서 이동: `WorldMap.Blocked`가 x 386 동쪽은 `Regions.EastBlocked`(열린 길·지역 안, 시설 발자국 제외)로 넘긴다. 카메라는 동쪽에선 x를 지역 끝까지 따라가고 y는 지역 띠(가운데 430)에 붙는다. 지면은 기지 텍스처(x −150~550)에 이어 동쪽 텍스처(x 550~1720)를 한 장 더 깔고, 두 장의 명암·비네트가 경계에서 같게 칠해진다(밝은 땅 = 기지·길·지역 사각형).
- 지도: 동쪽 지역을 알게 되면(2장 끝) 지도 위에 지역 탭 [기지][우주항][얼음 협곡]. 지금 있는 지역이 먼저 열리고, 아직 잠긴 다음 지역은 어두운 실루엣과 자물쇠만.
- 봇 격자는 x 0~1720까지.

## 3장 우주항

착륙장에 화물 우주선이 정기적으로 내려앉아(하강·역추진 불꽃·먼지 고리, 글자 없음) 정착민 무리와 주문을 가져온다. 주문은 물·산소·식량 묶음([아이콘] 숫자 칩)이고, 다 채우면 큰 벨 보상과 함께 정착민이 길로 내려가고 우주선은 이륙한다. 기존 문법: 캐기 → 가공 → 공급 → 발판 확장.

| 시설 | 모형(KayKit) | 하는 일 |
|---|---|---|
| 착륙장 A·B·C | landingpad_large + 화물선 lander_B | 착륙장마다 주문 하나. 관제탑이 높을수록 자주 온다 |
| 연료 공장 `fuel` | basemodule_D + 초록 탱크(roofmodule_cargo_A) | 물통 → 연료통(새 자원, 초록 통). 지붕 호퍼에 물통, 동쪽 받침대에 연료통 |
| 발사대 `launch` | landingpad_small + structure_tall 발사탑 + 흰 로켓 | 연료 30을 실으면 카운트다운 불빛 → 발사(수출, 벨) → 새 로켓이 솟아오름 |
| 관제탑 `tower` Lv1~3 | structure_tall + basemodule_E 돔 + 레이더 | 화물선 간격 ×0.8·0.65·0.5, 주문 보상 +10%/Lv |

## 4장 얼음 협곡

협곡을 열면 거대한 얼음 광맥(큰 얼음 덩어리 더미)과 정제소(basemodule_garage + 노란 탱크)가 선다. 광맥 둘레 얼음을 주워 정제소 호퍼에 넣으면 연료통이 나오고, 채굴 로버(spacetruck_large + 트레일러)가 광맥에서 얼음을 실어 정제소로 저절로 나른다. 연료는 우주항 발사대로. 벽은 KayKit 지형(terrain_tall·slope)을 메사 색으로 칠한 계단 절벽.

## 우주 연출

글자 없이: 하늘을 지나가는 궤도선 그림자(5장 생존 뒤, 1~2분마다 땅 위를 크게 쓸고 지나감), 밤에 먼 곳에서 오르는 발사 불꽃(3장부터), 우주항 착륙·이륙·로켓 발사. 관제사 무전은 장 시작과 새 지역 해제(1번 도로·우주항·협곡)만 한 줄.

## 진행 속도와 저장

목표 각 장 40~60분(봇 −timescale 8 측정, docs/pacing-report.md에 이어 적음). 10/27 측정에서 3장 봇 36~42분·4장 33~36분이었고, 17단계(정제 연료)가 16단계 뒤 20초 안에 지나가서 60 → 200으로 올렸다(표는 코드 SettlementManager 수치와 맞춤). 하루 미션에 화물선 주문·발사·연료 묶음이 더해지고, 2장 본부 보너스(판매가·기계 속도)는 그대로 우주항 공급 속도에 걸린다. 저장은 필드 추가만(S.orders·launches·arrivals·fuel…·ships), 옛 저장(2장 진행 중·10단계 완료)은 그대로 11단계부터 이어진다.
