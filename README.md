# 화성의 숲

붉은 행성에서 물병 가게를 키우는 피자레디식 타이쿤. 두 가지 버전이 한 저장소에 있다.

| 경로 | 무엇 | 용도 |
|---|---|---|
| `app/index.html` | **화성 물병 가게** (앱용, 세로 전용) | iOS 앱 본체. 피자레디 루프만 남긴 새 설계 |
| `index.html` | 화성의 숲 (웹, 가로·세로 모두) | 녹지화·주민·탈것까지 있는 원본 콜로니 게임 |

둘 다 바닐라 JS + three.js(`vendor/` 동봉, 오프라인 동작), 진행은 localStorage.

## 화성 물병 가게 (app/)

루프: 얼음 줍기 → 제빙기 → 병입기 → 카운터 → 손님 결제 → 벨 → 노란 발판을 밟아 업그레이드·고용·확장.

- **조작**: 화면 아무 데나 드래그하면 플로팅 조이스틱. 버튼 없음. 줍기·넣기·올리기·돈 줍기는 가까이 가면 자동.
- **발판 12종**: 손 크기, 제빙기·병입기 속도, 선반 칸, 간판(손님↑), 프리미엄 라벨(값↑), 삐걱 고용(계산 자동), 뽀삐 고용(운반 자동)·추가·속도, 얼음 드릴(채굴 자동), 휴게 돔(팁). 판매량에 따라 순서대로 열린다.
- **부재 중 수익**: 삐걱+뽀삐를 고용한 뒤 앱을 닫아도 최대 2시간치 벨이 쌓인다.
- **연출**: 3/4 시점 로우폴리, 걷기 바운스, 등짐이 이동 방향 반대로 쏠리는 스택, 아이템·동전 아크 비행, 발판 결제 코인, 건물 팝업, 손님 점프.
- 힌트 화살표가 다음 행동을 가리키므로 튜토리얼이 따로 없다.

## iOS 앱

`ios/`에 WKWebView 래퍼. `app/index.html`과 three.js를 번들에 넣고 `mars://app/` 커스텀 스킴으로 서빙한다(ES 모듈·localStorage 안정). 세로 고정, 상태바 숨김.

```bash
cd ios
./build.sh          # 시뮬레이터 빌드 → 켜져 있는 시뮬레이터에 설치·실행
./build.sh xcode    # Xcode 프로젝트 생성·열기 (실기기 서명·설치)
```

요구: Xcode, `brew install xcodegen`. 구조는 hanjul·menubar-pets와 같다(`project.yml` + `build.sh`). `ios/App/Web/`은 build.sh가 매번 만드는 산출물이라 git에 없다.
